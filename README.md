# Yapay Zekâda Reklam

Yapay zekâ ve reklam odağındaki web sitesi için Vite, React ve TypeScript başlangıç deposu.

## Başlangıç

```bash
npm install
npm run dev
```

Üretim derlemesi:

```bash
npm run build
```
